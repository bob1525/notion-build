# 页面树拖拽与复制

侧栏页面树可以换顺序、改层级，也可以复制一页或整棵子树。规则在 `planPageMove` 和 `planPageCopy` 里，服务端保存前会再算一次。

## 拖拽

每一行左侧有握把（`data-testid="page-drag"`）。按住握把移动超过 4 像素才开始拖，单击链接仍然会打开页面。

落点按指针在目标行里的高度分成三段：

| 位置 | 判定 | 结果 |
| --- | --- | --- |
| 上方约 28% | `before` | 插到这一页前面，父级与它相同 |
| 中间 | `inside` | 成为这一页的子页面 |
| 下方约 28% | `after` | 插到这一页后面，父级与它相同 |

因此：

- 同级重排：拖到兄弟页的上沿或下沿。
- 拖进另一页：落在目标行中间。新父级是目标页，位置落在该父级下同一置顶分组的末尾。
- 拖出到更高层级：把子页面拖到父页面（或更高祖先）的上沿或下沿。新父级变成目标页的父级；拖到根页面外侧时，父级变成空。

拖动时画一条插入线，或给目标行套上边框（`data-testid="page-drop-indicator"`）。松手后 `POST /api/workspaces/:id/pages/move`，在一个事务里写回受影响页面的 `parentId` 和 `position`。刷新后顺序还在。

置顶仍然优先于位置。未置顶的页面即使被拖到置顶页的上沿，也会被夹回未置顶分组的开头，不会插到置顶页前面。置顶页同理，不会掉到未置顶页后面。

## 禁止成环

一次移动的新父级是：

- `inside`：目标页自己
- `before` / `after`：目标页现在的父级

下面两种都会被拒绝，页面树保持原样：

- 目标就是正在拖的这一页。提示「不能把页面拖到自己身上」。
- 新父级是这一页自己，或它的子孙。这包括拖进子页面、孙页面，也包括拖到自己子页面的前面或后面（那种落点的父级仍然是自己）。提示「不能把页面拖进自己的子页面」。

判断用 `collectDescendantIds`，结果里包含正在拖的页面。客户端先算，不合法就不发请求。服务端用工作区里的全部页面再算一次，不合法返回 400 和同一句提示。指示线变红，这句话出现在树的上方，并且不推动下面的行；松手后再弹出一次提示。

`buildPageTree` 里原有的环检测还在。就算库里已经有互相指向的父级，渲染时也不会死循环。

## 复制

页面工具栏的「复制」有两个选择：

- 仅此页：只复制这一页，子页面仍留在原文下面。
- 包含子页面：按深度优先复制当前用户看得到的子孙。看不见的私有页不会被带上。

根页面的标题是「原标题 副本」。标题去掉空白后如果是空的，就用「未命名 副本」。子页面标题保持原样，这样能对上原文。副本的父级：根副本跟原文同一个父级，并排在该层末尾；子孙的父级改指向各自的新页面。

正文按块复制，包括类型、文字、行内标记、待办状态、代码语言、折叠、图片地址和宽度。块 id 全部换新。块上的 `parentId` 若指向同页的另一个块，会改到新 id，引用和折叠里的嵌套不会断。

副本的作者是当前用户，可见性是私有，不置顶。原文不改。

## 测试记录

新增单元测试 6 个，都在 `src/lib/tree.test.ts`：

| 测试 | 结果 |
| --- | --- |
| 同级拖到最前、中间、最后 | 通过 |
| 拖进另一页，再拖出来升一级 | 通过 |
| 拖到自己、子孙，或自己子页面旁边 | 通过，树不变 |
| 未置顶页不会插到置顶页前面 | 通过 |
| 只复制一页，标题加「副本」 | 通过 |
| 复制子树，并给空标题加上「未命名 副本」 | 通过 |
